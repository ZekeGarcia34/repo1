## Contents

- [Addition of integers](addition.md): an explanation and two worked examples.

## Collaboration workflow

A teammate forks this repository, adds an integer multiplication example, and opens a pull request back to this repository. The teammate also opens an issue suggesting an improvement. The repository owner reviews and merges the pull request, then fixes and closes the issue.
